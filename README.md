# 📚 Library Management System

A simple **Library Management System** built in **Python** using **Object-Oriented Programming (OOP)** concepts. This project is a command-line application that helps manage library books and basic library operations.

## ✨ Features

* Add new books
* Display all books
* Search for a book
* Issue a book
* Return a book
* Remove a book
* Menu-driven interface

## 🛠️ Technologies Used

* Python 3
* Object-Oriented Programming (OOP)

## 📂 Project Structure

```text
Library-Management-System/
│── main.py
│── README.md
```

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```
